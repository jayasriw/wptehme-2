# jPortal WordPress Job Board

jPortal is a professional WordPress job board and recruitment marketplace package.

## Included

- `wp-content/plugins/jportal-core`: application engine for jobs, companies, candidates, applications, saved jobs, alerts, messaging, reviews, plans, analytics, import/export, moderation, and email notifications.
- `wp-content/themes/jportal`: responsive theme with homepage, job archive, single job, company, pricing, dashboards, header, footer, and mobile UX.

## Feature coverage

- Job listings, featured jobs, related jobs, deadlines, automatic expiration, video and audio job descriptions.
- Advanced search and filters by keyword, location, category, type, remote, and salary.
- Employer dashboard, candidate dashboard, application tracking, candidate management, and resume profile fields.
- Company profiles, ratings, reviews, private messaging, saved jobs, and job alerts.
- Subscription plans, pricing page, monetization foundation, and featured listing controls.
- Admin analytics, moderation status, CSV export, settings, custom fields, taxonomies, and email notifications.
- Translation-ready WordPress code, responsive UI, customizable branding, and navigation support.

## Installation

1. Copy the repository into a WordPress installation.
2. Activate **jPortal Core** under Plugins.
3. Activate **jPortal** under Appearance > Themes.
4. Create pages using shortcodes: `[jportal_jobs]`, `[jportal_submit_job]`, `[jportal_candidate_dashboard]`, `[jportal_employer_dashboard]`, `[jportal_companies]`, `[jportal_pricing]`, `[jportal_messages]`.
5. Configure jPortal settings in the WordPress admin.
