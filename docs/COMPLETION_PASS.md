# jPortal Completion Pass

This pass adds final commercial support modules:

- Payment callback endpoint and manual paid-order activator.
- Subscription activation helper and plan usage filter.
- Threaded inbox foundation with replies.
- Review moderation shortcode and AJAX moderation.
- CSV import mapper.
- Onboarding shortcode.
- 12-layout demo renderer.
- Diagnostics admin page and shortcode.
- Payment return shortcode.
