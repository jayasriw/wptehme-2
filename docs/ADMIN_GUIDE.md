# jPortal Admin Guide

1. Activate jPortal Core and the jPortal theme.
2. Confirm the jPortal Commercial Suite mu-plugin is loaded from `wp-content/mu-plugins`.
3. Go to jPortal Suite > One-Click Setup.
4. Configure payment URLs or WooCommerce product under jPortal Suite > Payments.
5. Create plans under Plans, then use `[jportal_pricing]` and `[jportal_checkout plan_id="ID"]`.
6. Import jobs using jPortal Suite > CSV Import.
7. Use Polylang for multilingual pages. jPortal registers common strings when Polylang is active.
8. Use Elementor; jPortal registers 72+ widgets when Elementor is active.
9. Use the child theme for custom CSS or template changes.
