# jPortal Feature Matrix

This implementation provides feature-compatible modules for the requested commercial job board functionality.

## Core job board
- Job listing website functionality: implemented through job CPT and archive templates.
- Job board / freelance marketplace support: implemented with jobs, companies, candidates, applications, plans, proposals foundation, and dashboard shortcodes.
- Job posting and listing management: implemented through admin CPTs and front-end submit form.
- Featured jobs: implemented with `_jp_featured` metadata and listing badges.
- Related jobs: implemented through content append hook.
- Application deadline and expiration: implemented through deadline metadata and scheduled expiration.
- Video job descriptions and video/audio interviews: implemented through media URL fields and interview CPT.
- Moderation: implemented with pending status and moderation metadata.
- Resume/CV management: implemented with candidate profile fields and resume builder CPT.
- Apply options: implemented with AJAX application flow and external apply URL field.
- Alerts and email notifications: implemented through alert CPT and scheduled mail.
- Advanced search/filtering: implemented by keyword, location, category, type, remote, salary, skill, and taxonomy filters.
- Custom fields/taxonomies: implemented.
- Import/export: CSV export in core and CSV import in suite.
- Analytics: admin metrics and analytics shortcode.
- Responsive design: theme and plugin CSS.
- Social sharing: job detail share block.
- Multilingual: translation-ready and Polylang string registration.
- GDPR: cookie notice and cookie policy shortcode.
