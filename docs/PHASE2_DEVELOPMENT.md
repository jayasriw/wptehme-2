# jPortal Phase 2 Development

This pass adds pro modules for the remaining commercial feature gaps.

## Added

- Subscription CPT and paid access filters for job posting, featured jobs, and candidate contact access.
- Employer application pipeline shortcode with status updates.
- Candidate workspace combining resume upload, saved searches, recommendations, and messages.
- Resume upload with file type validation and print/PDF export foundation.
- Saved searches and recommendations.
- Advanced sidebar search layout.
- Map search data layer with provider-ready placeholder and lat/lng metadata.
- GDPR preference form.
- Revenue analytics shortcode.
